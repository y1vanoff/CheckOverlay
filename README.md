# CheckOverlay

Небольшой локальный интерактивный чеклист-оверлей для Windows 10 и Windows 11.

**Текущий этап — согласование дизайна.** Затем будет подготовлено техническое задание и начнётся разработка. Код приложения пока не реализован.

## Основные возможности

- Добавление, изменение, удаление и отметка выполнения задач.
- Окно поверх остальных, перемещение и регулировка прозрачности.
- Выбор цвета фона и изображения компактного режима.
- Локальное автосохранение, трей и включаемый автозапуск Windows.

Список не привязан к датам. История и интеграция с ChatGPT не планируются. Docker и сервер не нужны.
