# CheckOverlay

Небольшой интерактивный чеклист поверх рабочих окон Windows 11.

**Стадия: проект ТЗ и макет, версия 0.1.** Реализация ещё не начата. Предпочтительный стек — Tauri 2 + HTML/CSS/JavaScript.

## Документы

- [Техническое задание на MVP](docs/mvp-spec.md): требования, предложенные настройки и критерии приёмки.
- [Макет и прототип в Penpot](docs/design.md): экраны, переходы и дизайн.
- [Решения проекта](docs/decisions.md): текущий объём и следующие этапы.

## Возможности MVP

- Задачи с галочками, добавлением, редактированием и удалением.
- Перемещение окна, закрепление поверх других окон и прозрачность фона.
- Автосохранение задач и настроек на компьютере.
- Трей, скрытие по крестику и включаемый автозапуск Windows.

Приложение планируется локальным, без Docker и сервера. Синхронизация с ChatGPT — отдельный этап. Компактный режим показан в макете как предложение для согласования.

## Работа над проектом

Требования и макет согласовываются до реализации. Изменения ТЗ, дизайна и программы ведутся в этом репозитории отдельными коммитами. Документы различают согласованные требования и предложения. Публичные примеры задач обезличены.
