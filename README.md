# CheckOverlay

Локальный чеклист-оверлей для Windows 10/11 x64 на Tauri 2 и HTML/CSS/JavaScript.

## Реализовано в исходниках

- Ввод до 80 символов прямо в строке, изменение по двойному щелчку или F2/Enter, сохранение ✓/Enter, отмена Esc.
- Выполнение с мини-логотипом, удаление правой кнопкой, подтверждение и сохраняемое «Больше не спрашивать».
- Черновики, локальное последовательное автосохранение и безопасная замена JSON-файла.
- Очистка выполненных к 09:00 и после новой загрузки Windows (BootIdentifier).
- Компактный режим 100 × 100 логических px, перемещение, восстановление положения, настройки цвета и прозрачности.
- Логотип утёнка по умолчанию; импорт PNG/JPG/GIF с локальной копией и ограничениями.
- Трей, включаемый автозапуск, один экземпляр приложения.
- Раздельные логика, параметры оформления и системные функции.

## Проверка и сборка

Нужны Node.js 24+, Rust stable, Microsoft C++ Build Tools с Windows SDK и WebView2.

```powershell
npm ci
npm test
npx playwright install chromium
npx playwright test
npm run build
```

Установщик: `src-tauri/target/release/bundle/nsis/`. GitHub Actions выполняет проверки и Windows-сборку; готовый установщик появляется в артефактах успешного запуска. Подпись установщика пока не настроена.

`npm run icons` генерирует иконки перед сборкой. Для разработки: `npm run icons`, затем `npm run tauri -- dev`.

Для браузерного просмотра: `npm run preview` и `http://127.0.0.1:18719`. Это отдельные демонстрационные данные в браузере; трей, автозапуск и системное окно доступны только в Windows-приложении. Не запускайте preview как публичный сервер.

## Данные

Приложение хранит `state.json` и копии пользовательских иконок в каталоге приложения текущего пользователя Windows. Интернет после установки не требуется. Первый запуск — пустой список.

При повреждении файла приложение предлагает выбрать корректный JSON или явно начать новый список, сохранив повреждённый файл отдельно. Удаление приложения убирает регистрацию автозапуска; пользовательские данные автоматически не удаляются.
