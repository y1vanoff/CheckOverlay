# CheckOverlay

Небольшой интерактивный чеклист поверх окон Windows 11.

Сейчас проект находится на этапе технического задания и макета в Penpot. Предпочтительный стек будущей реализации — Tauri + HTML/CSS/JavaScript. Приложение планируется локальным; синхронизация с ChatGPT рассматривается отдельно.

Требования и макет проходят согласование перед началом реализации.
