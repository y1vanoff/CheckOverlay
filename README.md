# CheckOverlay

Локальный чеклист-оверлей для Windows 10/11 x64 на Tauri 2 и HTML/CSS/JavaScript. Версия 0.2.3 дополняет принятые [ТЗ v1.1](docs/mvp-spec.md) и [дизайн](docs/design.md) согласованными [11 правками интерфейса](docs/changes-0.2.1.md). [Статус проверки 0.2.1](docs/status-0.2.1.md).

## Возможности

- Montserrat Alternates из локальных файлов; согласованные строки, прогресс и иконка импорта из экрана 18.
- Добавление и изменение в строке до 80 воспринимаемых символов, внутренний счётчик и центрированные ✓/×. Tab сохраняет и открывает следующую задачу; потеря фокуса сохраняет допустимый текст. Незавершённый черновик сохраняется отдельно.
- Выполнение с мини-утёнком, удаление правой кнопкой, подтверждение и «Больше не спрашивать».
- Плашки с «Отменой» на 2,5 секунды: восстановление удалённой задачи или удаление только последней партии импорта.
- TXT в UTF-8: выбор кнопкой или перетаскивание на любой экран, одна непустая строка — одна задача, предпросмотр, исправление длинных строк, уникальное имя сохранённого снимка. Новый файл и сохранённые имена находятся на одном экране.
- Повторное добавление сохранённого списка по имени без исходного TXT; существующие дела не заменяются.
- Полное окно 320 × 470 по умолчанию: размер меняет только пользователь, положение и размер сохраняются между экранами. Тонкая прокрутка, нативное перемещение, прозрачный WebView и скруглённая внешняя область Windows. Acrylic не используется в пути перетаскивания.
- Сворачивание через fade без растягивания, с привязкой к текущему правому верхнему углу и компактная иконка 100 × 100 логических px. Системное отключение анимаций учитывается.
- Утёнок либо свой PNG/JPG/GIF, настройки цвета и прозрачности, трей, один экземпляр и включаемый автозапуск.
- Очистка выполненных в 09:00 и после новой загрузки Windows. Нет дат, истории, сервера и синхронизации.

Изменения 0.2.3: [прозрачность, системная рамка и fade](docs/changes-0.2.3.md).

## Проверка и сборка из исходников

Нужны Node.js 24+, Rust stable, Microsoft C++ Build Tools с Windows SDK и WebView2.

```powershell
npm ci
npm test
npx playwright install chromium
npx playwright test
npm run build
```

Установщик: `src-tauri/target/release/bundle/nsis/`. `npm run icons` генерирует иконки перед сборкой. Разработка: `npm run icons`, затем `npm run tauri -- dev`.

Браузерный просмотр: `npm run preview`, затем `http://127.0.0.1:18721`. Его задачи хранятся отдельно от Windows-приложения; нативные функции доступны в EXE. Для проверки в уже установленном Chrome можно задать `LOCAL_CHROME=1`. Не публикуйте сервер просмотра в интернете.

Для разработчика: запуск EXE с `--smoke-test` создаёт отдельный временный профиль `checkoverlay-smoke-<PID>`, не читает и не мигрирует основной список. Не запускайте его одновременно с обычным экземпляром: действует защита от двух процессов.

## Данные

Первый запуск — пустой список и пустая коллекция импортов. Интернет после установки не требуется. Формат `state.json` v2 хранит задачи, черновик, настройки и независимые снимки импортов в каталоге текущего пользователя Windows. Старый v1 переносится без потери задач и настроек; неизвестная версия не перезаписывается.

Пользовательские изображения копируются в каталог приложения. При повреждении файла можно выбрать корректный JSON или явно начать новый список, сохранив повреждённый файл отдельно. Удаление приложения убирает автозапуск; данные автоматически не удаляются.

TXT — UTF-8 с необязательным BOM, до 1 МиБ и 5000 непустых строк; основной JSON — до 2 000 000 байт. Большие операции, не помещающиеся в хранилище, завершаются сообщением об ошибке без частичного добавления. Снимок сохраняет только принятые строки; Markdown не интерпретируется. [Пример TXT](docs/examples/import-tasks.txt).
