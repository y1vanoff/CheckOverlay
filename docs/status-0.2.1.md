# Статус CheckOverlay 0.2.1

20 ноября 2026 года.

Исходники подготовлены в текущей рабочей папке на основе локальной версии 0.2.0. Перечень требований: [11 правок пользователя](changes-0.2.1.md).

## Проверено

- 23 теста логики: сохранение, валидация, миграция, импорт, отмена, очистка и геометрия.
- 27 сценариев интерфейса в установленном Chrome проверяют прежнее поведение и новые требования: Tab, автосохранение, отмену, клик по чекбоксу при открытом редакторе, неподвижность пустого списка при уведомлениях, перетаскивание TXT, центр палитры и целостность обводки. Все прошли.
- Имитация нативного моста проверяет отсутствие команд изменения геометрии при навигации, ручной размер в настройках, перемещение компактного/полного видов и нативные события перетаскивания.
- Просмотр скриншота поля ввода: зелёный контур целиком внутри границ; одна внешняя рамка стекла.

Для изоляции от ранее запущенного просмотра 0.2.0 сервер тестов использует порт 18721 и не переиспользует существующий процесс.

## Не проверено

Команда `npm run build` успешно сгенерировала иконки, затем остановилась на `cargo metadata`: `program not found`. Cargo недоступен; Microsoft C++ Build Tools также не обнаружены. Новый EXE и установщик не собраны; нативные тесты Rust не запускались. Исправление системной рамки Windows, реальная прозрачность, перетаскивание из Проводника, анимация и смена DPI требуют сборки Windows и проверки на рабочем столе. Проверки имитации моста не заменяют эти действия.

Для Windows-сборки сохранён существующий workflow `.github/workflows/check.yml`; локальная команда после установки инструментов — `npm ci`, `npm run build`, затем `cargo test --release --manifest-path src-tauri/Cargo.toml --locked`.

Установленное приложение и его пользовательские данные не заменялись.
