# Статус реализации

Актуализировано 19 ноября 2026 года. Ниже сохранены результаты первой реализации MVP от 18 ноября, принятой через PR #2. Они относятся к прежнему коду и не подтверждают соответствие [ТЗ v1.1](mvp-spec.md).

## Следующая доработка — после приёмки документационного PR

Согласованный дизайн опубликован в [галерее](design/approved-2026-11-19/README.md). В этом PR нет изменений приложения, зависимостей или тестов.

Требуют реализации/повторной проверки: точная компоновка и Montserrat Alternates; эталонная иконка импорта; тонкая прокрутка; настоящая прозрачность и системные скругления; быстрое перемещение; сворачивание в текущий правый верхний угол; временная отмена; TXT-предпросмотр, исправление, уникальные именованные снимки, повторное добавление и уведомление 2,5 секунды.

Макеты — состояния интерфейса, а не доказательство системного эффекта или анимации. Все новые проверки A-20–A-37 и прежние затронутые сценарии выполняются при последующей реализации.

## Проверено локально

- 11 тестов бизнес-логики Node.js: валидация, черновики, сортировка, очистка 09:00/новая загрузка, ошибка записи, восстановление монитора.
- 5 сценариев интерфейса Playwright в Chrome: ввод и изменение, удаление и «Больше не спрашивать», компактный режим, сохранение черновика, пустой список и повреждённые данные. Дополнительно проверен запуск при отказе записи через имитацию системного моста.
- Генерация иконок из предоставленных SVG.

## Проверено сборкой Windows

Установщик NSIS и отдельный EXE успешно собраны на Windows runner. Проходят 3 нативных теста Rust: стабильность BootIdentifier, замена файла и валидация изображения. Проверка API идентификатора загрузки также прошла на локальном Windows 10.

## Требует проверки на Windows-приложении

Нативные функции и установщик проверяются сборкой GitHub Actions, затем приёмкой установленного приложения. Браузерные проверки не доказывают работу трея, загрузочного GUID, автозапуска, Acrylic, системного выбора файла и восстановления окон.

Обязательные ручные проверки после сборки: запуск/установка на Windows 10 и 11; закрытие в трей; повторный экземпляр; включение/отключение автозапуска и удаление приложения; отключение монитора/DPI; импорт GIF/PNG/JPG; системное отключение анимации; перезагрузка, сон и пропущенные 09:00; отказ записи и повреждение файла.

## Практические ограничения

- Прозрачность: 0–70%, стекло имеет системное размытие при доступности Acrylic; поддержка эффекта должна быть проверена на конкретной версии Windows.
- Дополнительное ограничение GIF: суммарно не более 64 млн декодированных пикселей для защиты памяти.
- Код регистрации автозапуска не включается до явного действия пользователя.
- Сборка пока не имеет цифровой подписи.
