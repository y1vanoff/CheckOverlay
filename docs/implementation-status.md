# Статус реализации

Первая реализация MVP, 18 ноября 2026 года.

## Проверено локально

- 10 тестов бизнес-логики Node.js: валидация, черновики, сортировка, очистка 09:00/новая загрузка, ошибка записи, восстановление монитора.
- 5 сценариев интерфейса Playwright в Chrome: ввод и изменение, удаление и «Больше не спрашивать», компактный режим, сохранение черновика, пустой список и повреждённые данные. Дополнительно проверен запуск при отказе записи через имитацию системного моста.
- Генерация иконок из предоставленных SVG.

## Требует проверки на Windows-приложении

Нативные функции и установщик проверяются сборкой GitHub Actions, затем приёмкой установленного приложения. Браузерные проверки не доказывают работу трея, загрузочного GUID, автозапуска, Acrylic, системного выбора файла и восстановления окон.

Обязательные ручные проверки после сборки: запуск/установка на Windows 10 и 11; закрытие в трей; повторный экземпляр; включение/отключение автозапуска и удаление приложения; отключение монитора/DPI; импорт GIF/PNG/JPG; системное отключение анимации; перезагрузка, сон и пропущенные 09:00; отказ записи и повреждение файла.

## Практические ограничения

- Прозрачность: 0–70%, стекло имеет системное размытие при доступности Acrylic; поддержка эффекта должна быть проверена на конкретной версии Windows.
- Дополнительное ограничение GIF: суммарно не более 64 млн декодированных пикселей для защиты памяти.
- Код регистрации автозапуска не включается до явного действия пользователя.
- Сборка пока не имеет цифровой подписи.
