# Решения проекта

Дата: 18 ноября 2026 года.

## Согласовано

- Windows 11, небольшой интерактивный чеклист-оверлей.
- Добавление, редактирование, удаление и отметка выполнения задач.
- Поверх остальных окон, перемещение и регулировка прозрачности.
- Локальное автосохранение, трей и включаемый автозапуск.
- Крестик скрывает окно в трей.
- Сначала ТЗ и макет в Penpot, затем реализация.
- GitHub проекта: y1vanoff/CheckOverlay.

## Предпочтительный стек

Tauri 2 + HTML/CSS/JavaScript. Окончательный выбор подтверждается проверочной сборкой после согласования требований.

## Предложения для согласования

Тёмная панель; размер 380 × 700; прозрачность фона 0–50%; отмена удаления на 8 секунд; выполненные задачи внизу; один активный список; компактный режим. Детали и критерии приёмки находятся в [ТЗ](mvp-spec.md).

## Исключено

Docker отменён пользователем. Локальному MVP не нужен сервер.

## Отдельные этапы

Синхронизация с ChatGPT, история по дням, перенос задач на завтра, несколько списков, напоминания, глобальные горячие клавиши и сквозные щелчки.

## Ближайшее действие

Согласовать ТЗ и внешний вид. После этого проверить сборочную среду и приступить к реализации. Наличие макетов не означает готовность системных функций приложения.
