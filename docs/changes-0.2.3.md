# CheckOverlay 0.2.3 — прозрачность, рамка и fade

20 ноября 2026 года.

- Отключена системная отрисовка неклиентской области DWM. Обработчик Windows подавляет WM_NCPAINT и передаёт WM_NCACTIVATE без перерисовки рамки. Это устраняет источник белых углов компактной иконки и системного заголовка, просвечивающего сквозь интерфейс при смене фокуса. Остальные сообщения, включая изменение размеров и перемещение, передаются штатному обработчику; subclass снимается при уничтожении окна.
- Прозрачность настройки по-прежнему изменяет только альфа-канал фона CSS. Постоянная прозрачность всего окна не применяется; текст и элементы управления сохраняют свою непрозрачность.
- Сворачивание и разворачивание используют fade-out/fade-in по 120 мс. Размер и положение окна меняются один раз между фазами, когда интерфейс невидим. Удалены растяжение по двум осям, ResizeObserver с transform и нативная интерполяция размеров. Сохранены привязка к правому верхнему углу, геометрия, DPI и отключение анимации по системной настройке.
- Добавлены проверки невидимости в момент изменения геометрии, отсутствия transform, восстановления видимости после ошибки и независимости прозрачности фона от содержимого. Нативный тест проверяет DWM и обработку смены активности на отдельном скрытом окне Windows.

Основания для обработки Windows: [WM_NCACTIVATE](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-ncactivate), [политика DWM](https://learn.microsoft.com/en-us/windows/win32/dwm/composition-ovw), [SetWindowSubclass](https://learn.microsoft.com/en-us/windows/win32/api/commctrl/nf-commctrl-setwindowsubclass).

Результаты автоматической сборки не заменяют визуальную приёмку установленного приложения на Windows 10/11.
