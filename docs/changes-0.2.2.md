# CheckOverlay 0.2.2 — перетаскивание файла в Windows

20 ноября 2026 года. Исправление замечания пользователя к установленной 0.2.1.

Причина: в 0.2.1 события перетаскивания обрабатывались в `on_window_event`. Windows WebView2 передаёт перетаскивание из Проводника через `WebviewEvent::DragDrop`, поэтому обработчик окна не получал файл. Браузерная имитация сразу отправляла `native-file-drag` и не проверяла подключение к источнику нативных событий.

Исправление: подключить обработку в `on_webview_event`, явно включить `dragDropEnabled` в конфигурации окна. Сохранить существующий контракт фронтенда: наведение открывает импорт, отпускание передаёт проверенный TXT в предпросмотр. Добавлен нативный тест с настоящими типами `WebviewEvent` и чтением временного TXT.

Источник API: https://docs.rs/tauri/2.12.7/tauri/struct.Builder.html#method.on_webview_event

Ручную проверку на рабочем столе выполняет пользователь; успех сборки и нативного теста не обозначает, что перетаскивание из Проводника проверено вручную.
