# CheckOverlay 0.3.0 — согласованные изменения

23 ноября 2026. Дополнение к ТЗ v1.1; при расхождении для перечисленных функций действует эта редакция.

## Два списка и перенос
«На сегодня» и «Большие» хранятся одновременно, имеют независимые задачи и прогресс. Выбранная вкладка сохраняется. Существующие задачи и черновик v1/v2 мигрируют в «На сегодня». Перед первой записью v3 сохраняется state-before-v3.json; предыдущий установщик не поддерживает v3.

«Большие», включая выполненные задачи, сохраняются до ручного удаления. Очистка в 09:00 и после перезагрузки действует только на «На сегодня».

Кнопка-стрелка варианта 04 рядом с каждой большой задачей переносит её в конец «На сегодня» с сохранением ID, текста и отметки выполнения. Для выполненной задачи начинается новый срок хранения в ежедневном списке. После успешного сохранения показывается плашка «Задача перенесена на сегодня», «Отмена». Срок 2,5 секунды, плавное появление/исчезновение как у удаления. Отмена возвращает исходное положение и состояние; последующие изменения задачи не перезаписываются отменой старого действия. Ошибка записи оставляет исходный список.

Иконка импорта видна в обеих вкладках. Новый и сохранённый импорт добавляются только в «На сегодня», затем открывается эта вкладка.

## Фокус и ссылки
Тумблер «Сворачивать при фокусе на других окнах» выключен по умолчанию. При включении потеря фокуса нативного окна переводит приложение в существующий компактный режим 100×100 с fade версии 0.2.3. Возврат — нажатием на иконку, выбранный список сохраняется. Внутренние диалоги, системные диалоги выбора файлов и собственное меню не вызывают сворачивание.

HTTP/HTTPS URL в тексте обоих списков кликабельны и открываются в браузере по умолчанию. Переход не включает редактирование и не меняет отметку выполнения. В редакторе URL остаётся исходным текстом; лимит 80 графем сохраняется. Иные схемы не открываются. Работа с браузером учитывает тумблер потери фокуса.

## Дизайн и проверки
Согласованный снимок геометрии и оформления: [snapshot.json](design/two-lists-approved/snapshot.json). Экраны 01, 02, 03, вариант 04 и плашка 07. После фиксации снимка Penpot свободен для работы владельца.

Логика и браузерные сценарии проверяются автоматически, Windows EXE/NSIS — через Actions. Фактическое открытие браузера, фокус между Windows-приложениями и системные диалоги требуют ручной проверки установленного приложения.
