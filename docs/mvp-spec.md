# CheckOverlay — техническое задание на MVP

Версия 0.1 · 18 ноября 2026 года · **проект для согласования**

Репозиторий: https://github.com/y1vanoff/CheckOverlay

## 1. Назначение

Небольшое приложение для Windows 11, которое показывает интерактивный план дня поверх рабочих окон. Пользователь отмечает выполненные дела, добавляет и изменяет задачи, перемещает список в удобную часть экрана. Приложение работает локально без сервера, Docker, учётной записи и подключения к интернету.

Текущий этап: согласовать требования и макет в Penpot. Реализация и выбор окончательного способа сборки — следующий этап. Предпочтительный стек: Tauri 2 + HTML/CSS/JavaScript.

## 2. Статус решений

**Согласовано пользователем:** Windows 11; интерактивный чеклист; добавление, изменение и удаление задач; always-on-top; перемещение окна; регулировка прозрачности; автосохранение; трей; включаемый автозапуск; крестик скрывает окно в трей; задачи на 19 ноября как демоданные. Docker отменён. Синхронизация с ChatGPT отложена.

**Предлагается этим проектом ТЗ:** внешний вид, размеры окна, диапазон прозрачности, сочетания клавиш, правила сортировки, отмена удаления и компактный режим. Эти детали ещё не утверждены.

## 3. Объём MVP

Один пользователь, один активный список с заголовком и датой. Несколько проектов, календарный архив и автоматический перенос задач между днями в MVP не входят. Дата списка не меняется автоматически в полночь. Название и дату можно изменить двойным щелчком по заголовку; изменение даты не очищает список. Начальный демосписок датирован 19.11.2026.

### F-01. Задачи

- Задача содержит идентификатор, текст, отметку выполнения и порядок в списке.
- Добавление: кнопка «Добавить задачу» открывает редактор с пустым полем.
- Текст — от 1 до 500 символов после удаления пробелов по краям; разрешены переносы строк. Пустую задачу сохранить нельзя: поле показывает ошибку.
- Щелчок по чекбоксу переключает выполнение. Повторный щелчок возвращает задачу в работу.
- Двойной щелчок по тексту открывает редактор. Изменения применяются только кнопкой «Сохранить» или Enter. Shift+Enter вставляет перенос строки; Escape отменяет редактирование.
- В редакторе существующей задачи есть команда «Удалить задачу». После удаления в основном окне на 8 секунд появляется «Задача удалена · Отменить». Отмена возвращает текст, статус и положение задачи.
- Незавершённые задачи показываются первыми, выполненные — внизу с галочкой и зачёркиванием. Внутри каждой группы сохраняется порядок добавления; снятие отметки возвращает исходное место среди незавершённых.
- Настройка «Показывать выполненные» скрывает или показывает выполненную группу, не удаляя её.
- Счётчик показывает число выполненных из общего числа; прогресс соответствует этому отношению. При пустом списке — 0 из 0 и пустая полоса.

### F-02. Окно-оверлей

- Окно без стандартной рамки Windows; в заголовке есть зона перетаскивания и кнопки управления. Элементы управления не начинают перетаскивание.
- По умолчанию: 380 × 700 логических пикселей, ширина изменяется от 340 до 560, высота — от 320 до 900 с ограничением рабочей областью текущего монитора. Длинный список прокручивается; заголовок и добавление остаются доступны.
- Начальное положение — у правого края рабочего стола с отступом 24 логических пикселя. Панель задач не перекрывается.
- Режим «Поверх остальных окон» включён по умолчанию; переключается кнопкой-булавкой, в настройках и через трей. Это обычный always-on-top Windows; отдельные полноэкранные приложения и системный защищённый экран не являются целевыми сценариями.
- Перемещение между мониторами, работа при масштабе Windows 100%, 125%, 150% и 200%. Положение и размер запоминаются; если монитор отключён, окно возвращается в видимую рабочую область доступного монитора.
- Окно не перехватывает фокус во время работы в другом приложении. Для ввода нужно щёлкнуть по нему.

### F-03. Прозрачность

- Ползунок «Прозрачность фона»: от 0% до 50%, шаг 5%, начальное значение 10%.
- 0% означает полностью плотный фон. Меняется только фон панели; текст, галочки и кнопки остаются непрозрачными.
- Изменение видно сразу и сохраняется. Прозрачность не означает прохождение щелчков сквозь окно: область панели остаётся интерактивной.

### F-04. Трей и завершение

- Приложение имеет значок в области уведомлений Windows.
- Крестик и кнопка с минусом скрывают окно в трей, сохраняя процесс и данные. При первом скрытии показывается короткое пояснение о том, как вернуть окно.
- Левый щелчок по значку показывает окно и переводит его на передний план. Правый щелчок открывает меню: «Показать чеклист», «Настройки», «Поверх остальных окон» с отметкой, «Выйти из приложения».
- Только команда «Выйти из приложения» завершает процесс. При наличии несохранённых изменений выход блокируется с выбором «Повторить сохранение», «Вернуться» или «Выйти без сохранения».
- Повторный запуск приложения открывает существующее окно, не создавая второй процесс с отдельным списком.

### F-05. Автосохранение и восстановление

- Хранение в каталоге данных приложения текущего пользователя Windows. Права администратора не требуются.
- После добавления, редактирования, отметки выполнения, удаления и изменения настроек запись запускается автоматически, без отдельной кнопки. Цель — закончить сохранение не позднее 1 секунды после последнего изменения при штатной работе диска.
- Запись последовательная, через временный файл и замену основного; сохраняется последняя корректная резервная копия. Структура данных содержит версию формата.
- Статусы: «Сохраняем…», «Сохранено на компьютере», «Не удалось сохранить». Сообщение об успехе появляется только после подтверждённой записи.
- При ошибке изменения остаются в памяти; появляется команда повторить сохранение. Нельзя незаметно заменить пользовательские задачи демосписком или пустым списком.
- При повреждении файла приложение предлагает восстановить резервную копию. Повреждённый файл сохраняется для диагностики.
- Демоданные добавляются только при первом запуске, когда файла данных ещё нет. Если пользователь удалил все задачи, при следующем запуске список остаётся пустым.
- Сохраняются список, заголовок/дата, выполнение, размер и положение окна, прозрачность, закрепление поверх окон и показ выполненных. Статус автозапуска читается из настроек Windows и не подменяется локальным флагом.

### F-06. Автозапуск

- По умолчанию выключен. Включается явно переключателем «Запускать вместе с Windows».
- После включения приложение запускается при входе этого пользователя в Windows; права администратора не нужны.
- После обычного запуска и входа в Windows показывается чеклист. Не восстанавливается скрытие, вызванное крестиком в предыдущем сеансе.
- Если Windows отклонила изменение автозапуска, переключатель возвращается в фактическое состояние и показывается понятная ошибка.
- Удаление приложения должно удалять его запись автозапуска.

## 4. Предложение: компактный режим

Дополнение к базовому MVP, требующее согласования. Кнопка со стрелкой сворачивает окно до панели 380 × 88 логических пикселей с датой и счётчиком. Следующий щелчок восстанавливает список и его предыдущий размер. Это отдельное действие от скрытия в трей. Перемещение и режим поверх окон сохраняются. Без согласования компактный режим можно исключить, убрав кнопку из заголовка.

## 5. Интерфейс и макеты

Дизайн: тёмная зелёно-графитовая панель, светлый текст, мягкий зелёный акцент. Скругление панели 18 px, внутренних элементов 8–12 px; базовые отступы 24 px. Основной текст 14 px, дата 27 px. Шрифт макета — Inter; для приложения допустим Segoe UI, если переносы и размеры будут повторно проверены.

Макеты в Penpot:

1. Основной список — все семь задач не выполнены, 0 из 7.
2. Настройки — закрепление, прозрачность, автозапуск, показ выполненных, пояснение о трее.
3. Редактор задачи — текст, сохранение, отмена и удаление.
4. Компактная панель — предлагаемое дополнение.
5. Пустое состояние.
6. Меню трея.
7. Ошибка сохранения.

Кликабельный прототип дополнительно иллюстрирует переходы между списком, настройками и редактором; отметку одной задачи и возврат в исходное состояние. Это демонстрация экранов, а не работающая программа: ввод, перемещение, реальные настройки Windows и запись на диск в Penpot не выполняются.

Элементы управления доступны по Tab; Enter/Space активируют выделенную кнопку или чекбокс. Контраст основного текста и интерактивных элементов проверяется при 0% и 50% прозрачности на светлом и тёмном фоне. Состояние выполнения передаётся галочкой и зачёркиванием, а не только цветом. У каждой кнопки-значка есть подсказка и доступное имя.

## 6. Демоданные

Публичные примеры обезличены. Персональный макет в локальном Penpot использует рабочий список пользователя на 19 ноября 2026 года. В публичных файлах все задачи изначально не выполнены.

1. Принести диск с файлами.
2. Заняться личным проектом.
3. Отправить четыре письма заказчику и сохранить оригиналы.
4. Подготовить комплект закрывающих документов для заказчика.
5. Отправить коммерческое предложение.
6. Настроить доступ к сервису.
7. Отправить ответ на обращение.

## 7. Техническое направление

Предпочтительно Tauri 2: интерфейс HTML/CSS/JavaScript, системные функции в Rust. Используется установленный в Windows WebView2. Локальное хранилище и системные функции доступны только окну приложения; произвольный доступ к файловой системе, внешним адресам и выполнению команд не нужен.

Целевая сборка — Windows 11 x64, установщик для текущего пользователя. Выбор Tauri окончательно проверяется отдельной сборкой после согласования ТЗ. На проверенном компьютере Rust и Microsoft C++ Build Tools пока не обнаружены, а загрузка npm-зависимостей завершилась сетевой ошибкой. Это ограничение среды сборки, а не готового приложения.

Итог реализации: исходники в репозитории, воспроизводимая инструкция сборки, установщик, краткая инструкция пользователя и результаты проверки на Windows 11. На текущем этапе эти артефакты ещё не созданы.

## 8. Критерии приёмки реализации

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| A-01 | Первый запуск | Семь демозадач на 19.11.2026, 0 из 7, автозапуск выключен. |
| A-02 | Создать, изменить и выполнить задачу | Текст и счётчик обновляются; снятие галочки возвращает задачу в работу. |
| A-03 | Удалить задачу и нажать «Отменить» | Возвращаются её текст, статус и порядок. |
| A-04 | Удалить все задачи, выйти и открыть приложение | Пустой список сохраняется, демоданные не появляются повторно. |
| A-05 | Перезапустить приложение после изменений | Задачи, отметки и настройки восстановлены. |
| A-06 | Переместить, изменить размер, перезапустить; отключить второй монитор | Окно восстанавливается в доступной области экрана. |
| A-07 | Работать в другом обычном окне | При включённом закреплении чеклист остаётся сверху и не перехватывает фокус. |
| A-08 | Изменить прозрачность от 0% до 50% | Меняется фон; текст и управление остаются читаемыми и доступными. |
| A-09 | Нажать крестик, вернуть окно из трея; запустить второй экземпляр | Процесс продолжает работать; возвращается тот же список, второго экземпляра нет. |
| A-10 | Включить автозапуск, выйти из Windows и войти | Чеклист появляется. После отключения настройки повторный вход его не запускает. |
| A-11 | Имитировать отказ записи и повреждение файла | Нет ложного статуса «Сохранено»; доступны повтор и восстановление, исходные данные не затираются. |
| A-12 | Масштаб 100/125/150/200%, клавиатура, длинные строки | Управление доступно, текст не перекрывает кнопки, список прокручивается. |
| A-13 | Отключить интернет | Все функции MVP продолжают работать. |

2. Проверить сборку Tauri в подходящей среде и реализовать локальный MVP по критериям приёмки.

Дополнительные возможности — история по дням, перенос задач на завтра, несколько списков, напоминания по времени, глобальные горячие клавиши и сквозные щелчки — рассматриваются после MVP.
